# Security Policy

## Supported Versions

Only the latest major version receives security fixes. Please upgrade to the
latest release before reporting an issue.

| Version | Supported |
| ------- | --------- |
| 2.x     | Yes       |
| < 2.0   | No        |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues, pull
requests or discussions.

Instead, report them privately through
[GitHub private vulnerability reporting](https://github.com/hayawata3626/team-approval-checker/security/advisories/new).

Please include:

- the version (tag or commit SHA) of the action you are using
- a description of the issue and its impact, for example how an approval check
  can be bypassed or how a token can be exposed
- steps to reproduce, including the workflow configuration and the `conditions`
  input

You can expect an initial response within 7 days. Once the issue is confirmed, a
fix will be released and a security advisory will be published.
